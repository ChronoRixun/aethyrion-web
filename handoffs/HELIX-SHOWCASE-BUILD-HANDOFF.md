## 📋 PROJECT OVERVIEW

### What We're Building:
A professional static showcase page that displays 10 real components generated by Helix using 7 different AI providers. The page demonstrates:
- Component quality and variety
- Preset comparison (Base vs shadcn/ui)
- AI error fixing capability
- Multi-provider flexibility
- Production-ready output

### Why This Matters:
Helix just launched (v1.0) and needs a web presence to show what it can actually do. Screenshots + code samples are enough to convince visitors to download. We can upgrade to interactive demos later.

### Success Criteria:
✅ Matches aethyrion.org visual design (brand consistency)  
✅ Shows all 10 components with screenshots  
✅ Highlights unique features (presets, error fixing, 12 providers)  
✅ Mobile responsive  
✅ Fast load times  
✅ Clear CTAs (download Helix)  
✅ Deployable to Cloudflare Pages with helix.aethyrion.org subdomain

// Toggle code visibility
function toggleCode(componentId) {
    const codeSection = document.getElementById(`code-${componentId}`);
    if (codeSection.style.display === 'none') {
        codeSection.style.display = 'block';
    } else {
        codeSection.style.display = 'none';
    }
}

// Show specific code file in tabs
function showCode(componentId, fileType) {
    // Hide all code blocks for this component
    const allBlocks = document.querySelectorAll(`[id^="code-${componentId}-"]`);
    allBlocks.forEach(block => block.style.display = 'none');
    
    // Show selected code block
    const selectedBlock = document.getElementById(`code-${componentId}-${fileType}`);
    if (selectedBlock) {
        selectedBlock.style.display = 'block';
    }
    
    // Update active tab
    const tabs = document.querySelectorAll(`[onclick*="${componentId}"]`);
    tabs.forEach(tab => tab.classList.remove('active'));
    event.target.classList.add('active');
}

// Smooth scroll for anchor links
document.querySelectorAll('a[href^="#"]').forEach(anchor => {
    anchor.addEventListener('click', function (e) {
        e.preventDefault();
        const target = document.querySelector(this.getAttribute('href'));
        if (target) {
            target.scrollIntoView({ behavior: 'smooth' });
        }
    });
});
